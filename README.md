# LeoNav

App Android e iOS (Flutter) per la navetta aziendale: prenotazione di andata e ritorno con scelta della fermata, lista fermate per l'autista, posizione in tempo reale e pannello web per l'amministratore. Backend: Supabase.

## Contenuto

- `data/fermate.csv`: le 5 linee con le fermate e gli orari del mattino (dall'informativa mobility). Il ritorno parte per tutte alle 16:45. Le coordinate GPS sono da aggiungere.
